Eligibility & System Rules

Automated verification logic

  • CGPA Criterion Verification

    The student's current CGPA is evaluated against the company's minimum threshold: Student CGPA ≥ Eligibility CGPA. Ineligible candidates cannot submit.

  • Duplicate Prevention Enforced

    The system prevents duplicate registrations for the same company drive using a composite constraint UNIQUE (student_id, company_id).

  • Automatic Timestamp & Defaults

    Submissions automatically assign the current system date with default recruitment Round: 'Applied' and Status: 'Pending'.
